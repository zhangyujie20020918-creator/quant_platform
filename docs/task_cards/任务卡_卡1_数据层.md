# 任务卡 · 卡1 数据层

开工:2026-08-26 | 前置:卡0 完成(commit 34a2b50) | 蓝图:第六节 + 原则1/2/4

## 一、定义(做什么)

机制四件 + 首批表 + 日历落盘 + 体检四项 + 字段单位表。**只定机制,表清单按示踪弹最小需求定,后续策略按需追加。**

1. `data/schema.py` —— 表注册表:每表一份 TableSpec(列/类型/主键/日期列/来源优先级覆盖)。统一口径:`date` 为 datetime64;`symbol` 为 `600000.SH` 形式(所有来源映射到此);数量单位:volume=股,amount=元。
2. `data/store.py` —— 来源无关的读写:`cache/{table}/_parts/{source}__{chunk}.parquet` 分片 → `cache/{table}/{table}.parquet` 合并(按主键去重、按日期排序、带 `source` 溯源列);`read_table(name, start, end, symbols, columns)`;`table_status`。
3. `data/fetchers/` —— 来源适配器:`base.Source` 接口(`supports(table)` / `plan(table, start, end, cfg)` → 分片键列表 / `fetch(table, chunk)` → 统一schema DataFrame);`tushare.py`(requests 直连代理,协议同官方)、`akshare.py`(备源)。**分片策略属于来源**(Tushare 按日批量、AKShare 按标的),编排层不感知。
4. `data/fetch.py` —— 编排:按来源优先级取第一个支持该表的来源 → 规划分片 → 逐片拉取(已存在分片跳过=断点续传)→ 单片失败重试后记 `cache/fetch_failures.csv` → 来源整体不可用(鉴权/连接)则切下一来源重新规划 → 合并。CLI:`python -m data.fetch --tables a,b --start --end`。
5. `data/quality.py` —— 体检四项 → `reports/{日期}_数据体检/` 报告(md + csv):①退市样本在否 ②PIT时点正确性 ③脏值扫描 ④逐日覆盖曲线。CLI:`python -m data.quality`。
6. 交易日历:`trade_cal` 表拉取后导出 `cache/calendar/trading_days.csv`,`core.calendar` 自动切到文件模式。
7. `data/DATA_DICTIONARY.md` —— 字段单位表,S1 例行维护。

**首批表(示踪弹"沪深300成分低波20只月调"最小需求 + 品种红线所需)**:

| 表 | 内容 | 主源分片 | 备源 |
|---|---|---|---|
| trade_cal | 交易日历(交易所开市日) | tushare 单次 | akshare |
| stock_basic | 股票基本信息,**含退市/暂停上市**(list_status L/D/P) | tushare 按状态3次 | akshare(上市+退市两表) |
| stock_daily | 股票日线 OHLCV+amount(不复权,**原始存储,复权在读端做**) | tushare 按交易日 | akshare 按标的(仅修补用) |
| adj_factor | 复权因子 | tushare 按交易日 | 无(各源因子基准不同,不可混用,声明局限) |
| namechange | 历史名称变更(ST 状态来源) | tushare 分页 | 无 |
| index_daily | 指数日线 | tushare 按指数 | akshare 按指数 |
| index_weight | 指数成分与权重(月度快照) | tushare 按指数×年 | 无(akshare 仅当前成分,不可作历史) |
| fund_daily | ETF 日线 | tushare 按标的×区间 | akshare 按标的 |

指数与 ETF 清单在 `config.data.symbols` 里维护,不写死。

## 二、公式(怎么判定对错)

- 统一 schema 校验:缺列/主键重复/日期不可解析 → 拒绝写入(`schema.validate`)。
- 断点续传:同一 `(source, chunk)` 分片文件存在即跳过;`--force` 重拉。
- 来源切换判据:连续 N 次(config `data.fetch.source_fail_threshold`)分片级失败或鉴权错误 → 该来源标记不可用,切备源。
- 体检四项判据(阈值全部在 `config.quality`,批前声明):
  ①退市:`stock_basic` 中 `list_status=D` 计数 ≥ `min_delisted_count`,且抽样退市股在 `stock_daily` 有退市前行情;
  ②PIT:`index_weight` 快照日期单调且间隔 ≤ `max_snapshot_gap_days`;`namechange` 区间无重叠;`stock_daily` 无晚于 `trade_cal` 最新开市日的记录;
  ③脏值:价格 ≤0、high<low、vol<0、close 缺失但 vol>0 的行数占比 ≤ `max_dirty_ratio`;
  ④覆盖:每交易日在册股票数曲线,相对 `stock_basic` 当日应在册数的覆盖率 ≥ `min_daily_coverage`,低于阈值的日期列出。
