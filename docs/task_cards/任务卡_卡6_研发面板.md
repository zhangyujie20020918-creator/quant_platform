# 任务卡 · 卡6 研发面板(Streamlit 两屏:回测浏览器 / 因子 tear sheet,只读 reports)

开工:2026-08-28 | 前置:卡5 人类验收放行 | 蓝图:原则7(产出只经 outputs;面板只读 reports 永不写)+ 第八节卡6

## 一、定义(做什么)

一个本地 Streamlit 面板,把 reports/ 下卡3~5 的产出**读出来看**:回测浏览器(净值/回撤/指标/成交/持仓权重)、
因子 tear sheet(裁决总表/对照组/tear sheet 图/IC·分组表)、信号文件浏览、报告 md 阅读。里程碑:**浏览器里看到卡3~5 的产出**。
面板不计算、不落盘、不改任何文件;所有解析逻辑在纯 python 目录扫描/加载模块里(可测试),Streamlit 只负责渲染。

## 二、机制

### 1. 目录扫描 `dashboard/catalog.py`(纯函数,只读)
`scan_reports(root)` 扫 `reports/{YYYY-MM-DD}_{topic}/`,识别:
- 回测 run:`*_runs/` 下含 RQAlpha 报表(portfolio.csv / trades.csv / stock_positions.csv / summary.xlsx);
- 净值对比:`*_navs.csv`(date + 多列净值);
- 因子批次:含 `factor_verdict.md` 的目录 + `tear_<id>_runs/`(png + `<id>_ic.csv` + `<id>_quantile_returns.csv`);
- 信号:`{date}_信号_{strategy}/orders_*.csv` + `signal_log.md`;
- 报告:所有 md。
返回结构化 Catalog;扫描与加载**不得创建/修改任何文件**(测试断言文件集合不变)。

### 2. 加载与解析 `dashboard/loaders.py`
`load_rq_portfolio / load_rq_trades / load_rq_positions / load_summary(summary.xlsx) / load_navs / parse_md_table(md, 表头关键字)`
→ DataFrame;净值指标复用 `backtest/metrics.py::nav_stats`(自 run_toy_backtest 抽出,单一口径)。

### 3. 面板 `dashboard/app.py`(`streamlit run dashboard/app.py`)
侧栏四屏:①回测浏览器 ②因子 tear sheet ③信号 ④报告。reports 根目录来自 config `meta.reports_dir`,
环境变量 `QUANT_PLATFORM_REPORTS` 可覆盖(测试钩子)。图表用 Streamlit 内置(本地渲染,不依赖外网)。

### 4. 测试
- 合成 reports 树(tmp_path)上的扫描/加载/解析测试;只读断言;
- `streamlit.testing.v1.AppTest` 无头跑 app.py:四屏切换无异常、关键标题出现。

## 三、判据(放行条件)
- catalog/loaders 测试全绿,只读断言通过;AppTest 无异常;
- 真实 reports 上启动面板,能看到卡3 交叉验证净值与 RQAlpha 报表、卡4 裁决总表与 tear sheet 图、卡5 信号文件;
- CHANGELOG;面板代码零写文件调用(代码审查项)。

## 四、验收(人类看什么)
`streamlit run dashboard/app.py` 打开浏览器,四屏各看一眼;`reports/{日期}_卡6面板/smoke.md` 记录 AppTest 结果与截屏说明。

## 五、风险与未知
- Streamlit 版本与 numpy 1.26 / pandas 2.2 的兼容;summary.xlsx 中文键名读取(openpyxl)。
- AppTest 对 st.image / 大 png 的处理;超时设置。
