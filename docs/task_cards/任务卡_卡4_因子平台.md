# 任务卡 · 卡4 因子平台(registry + 防挖矿协议平移 + 检验管线 + alphalens/quantstats 接入)

开工:2026-08-28 | 前置:卡3 人类验收放行 | 蓝图:第三节 factors/ + 第八节卡4 | SOP:S2 因子构建

## 一、定义(做什么)

建一条**资产无关**的因子研究流水线:登记(五要素)→ 计算(date×symbol 面板)→ 检验(IC/ICIR/分组单调/换手,
样本内外切分,BH 校正,阳性/阴性对照)→ 裁决写回注册表 → alphalens tear sheet(T+1 口径锁死)。
里程碑:**任一因子出完整 tear sheet**(真实数据,沪深300 PIT 成分)。策略用的复合打分/组合搜索不在本卡。

从 cb_quant 平移(思想与制度,代码重写):防挖矿协议全文、注册表状态机、forward_returns T+1 口径、
IC/ICIR/t 检验、BH 校正、裁决规则。**去掉** active 上限(SOP v2:active 不设上限)与转债特化内容。

## 二、机制与公式(数值全部在 config.protocol,代码只写机制)

### 1. 注册表 `factors/registry.yaml`(唯一权威,代码只读;裁决由管线写回)
五要素必填:`id / formula / direction(higher_better|lower_better|to_be_tested) / hypothesis / category`;
另 `name / data_deps / lookback / status / role(candidate|positive_control|negative_control) /
data_version / test_report / oos_evaluated / redundant_with / notes`。
状态机:`candidate → tested → active | tested_weak | rejected`;**rejected / tested_weak 永不删除**。
`to_be_tested` 的方向由样本内 IC 符号判定后写回,hypothesis 追加"方向由样本内IC判定于<日期>",禁止事后补叙。

### 2. 因子实现 `factors/lib/<id>.py`
统一签名 `compute(ctx) -> DataFrame(date×symbol)`,ctx = {"close": 后复权收盘面板, "open": 后复权开盘面板,
"symbols": universe 全集, "cfg": config};向量化,全历史一次算完。数据只经 `backtest.prices.adjusted_panels`(store)。
rolling 一律 `min_periods = ceil(窗口 × protocol.min_periods_ratio)`,不足记 NaN。

### 3. 前瞻收益(T+1 锁死,唯一入口 `factors/forward_returns.py`)
信号日 T 用 T 收盘算因子;收益 = open[T+1+H] / open[T+1] − 1(T+1 开盘买、T+1+H 开盘卖,与回测执行口径一致)。
买/卖价 ≤0 或缺失 → NaN。**任何直接用 close[T] 起算的收益视为违规**;alphalens 封装入口同样只接受此口径。

### 4. 检验统计 `factors/ic.py` / `factors/quantiles.py`
- 信号日:`protocol.signal_freq`(默认 monthly_first,与 H=20 非重叠);IC = 逐信号日截面 Spearman(样本 <3 跳过);
  ICIR = mean/std;t 检验(H0: IC 均值=0)给 p 值供 BH。
- 分组:逐信号日按因子分 `protocol.n_quantiles` 组,组均前瞻收益;单调性 = 组序号与组均收益的 Spearman 相关(−1~1);
  换手 = 相邻信号日同组成员变动比例(top 组)。
- 样本切分:`protocol.in_sample / out_of_sample`(日期区间);**批前声明**写入报告首节(阈值+切分+候选总数),先于任何数字。

### 5. 裁决 `factors/verdict.py`(全部阈值读 config.protocol)
active ⇔ 样本内 |IC| ≥ ic_min ∧ |ICIR| ≥ icir_min ∧ |单调性| ≥ monotonicity_min ∧ 样本外 IC 同号
∧ |IC_oos| ≥ oos_retention_min × |IC_is| ∧ BH 校正后显著(bh_alpha)。
否则:样本内有信号(|IC| ≥ ic_min)但其余不满足 → tested_weak;样本内无信号 → rejected。
冗余:与全部 active 因子的秩相关 |ρ| > redundancy_corr_max → `redundant_with` 标注(active 不设上限,只标注)。
**样本外每因子只评估一次**:registry `oos_evaluated` 非空的因子,管线拒绝再算样本外(报告写"已终审")。

### 6. 对照组(强制,每批)
- 阳性对照:`role: positive_control` 的已知因子(首批:20 日反转 `rev_20`,A股最稳健异象之一)。首批建立基线
  (IC_is 写入 registry `control_reference`),其后每批复现须 |IC − 基线| ≤ positive_control_tolerance × |基线|,
  且方向与登记一致、|IC| ≥ ic_min;不达标 → 本批检验作废(管线报错,不出裁决)。
- 阴性对照:`role: negative_control` 的随机因子(种子 `protocol.negative_control_seed`)必判非 active;
  若判 active → 管线报错。

### 7. alphalens / quantstats 薄封装
- `factors/alphalens_wrapper.py::tear_sheet(factor_panel, opens, out_dir, periods)`:价格面板在入口强制取
  open.shift(−1)(T+1 开盘),再交 alphalens `get_clean_factor_and_forward_returns` + full tear sheet,图存 PNG,
  统计表存 CSV;**裸调用 alphalens 视为违规**(代码审查项)。
- `backtest/quantstats_report.py::nav_report(nav, benchmark, out_html)`:净值 → quantstats html 报告。
- 产出一律经 core.outputs(`reports/{日期}_卡4因子检验/`)。

### 8. 入口 `python -m factors.run_factor_tests [--date] [--factors id,...] [--universe 000300.SH]`
读注册表 → 取 universe 全历史成分 → 面板 → 逐因子计算 → 检验 → 对照 → BH → 裁决 → 写回 registry
(status/direction/test_report/data_version/oos_evaluated)→ 报告(批前声明 + 每因子一行裁决总表 + 冗余矩阵)
→ 对 active/tested_weak 因子各出一份 tear sheet。

## 三、判据(放行条件)
- 注册表机制 + 首批因子(vol_20 候选;rev_20 阳性对照;random 阴性对照;mom_20 候选)登记并可计算;
- 管线各环节有测试(合成面板,不触网):T+1 锁死、IC/ICIR/t、分组/单调/换手、BH、裁决(阈值来自 cfg)、
  对照组失败会报错、样本外只评估一次;
- 真实数据跑通:报告 + 至少一份完整 tear sheet + quantstats 报告;
- 批前声明先于结果;裁决写回注册表;CHANGELOG。

## 四、验收(人类看什么)
1. `reports/{日期}_卡4因子检验/factor_verdict.md`:批前声明、裁决总表、对照组结论、冗余矩阵;
2. tear sheet 图(至少 vol_20)与 quantstats html;
3. `factors/registry.yaml` 写回结果;测试全绿。

## 五、风险与未知
- alphalens-reloaded 0.4.6 与 pandas 2.2.3 的兼容性(已装,待实测);tear sheet 绘图在无显示环境用 Agg。
- 月频信号 × 20 日持有,样本内约 120 个截面,IC t 检验功效有限——如实报告 n。
- 首批阳性对照只能"建立基线",不能证明管线正确;真正的阳性检验从第二批起。
- 沪深300 大盘股上的短期反转/低波异象强度弱于全市场,结论只对该 universe 有效。
