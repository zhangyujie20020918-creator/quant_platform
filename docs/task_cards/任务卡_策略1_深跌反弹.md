## 一、定义(用户原话 → 平台口径;**下表即批前声明,回测前不再改;要改先改这里并记账**)

| 用户原话 | 平台口径(默认解释) | 落点 |
|---|---|---|
| 剔除科创板、ST、ETF、可转债,只在创业板和主板 | universe = stock_basic.market ∈ {主板, 创业板},上市日 ≤ 信号日 < 退市日(PIT,含已退市防幸存者偏差);ST 按 namechange 当日名称剔除;ETF/可转债本就不在股票池 | `instruments.universe.BoardUniverse` + `ctx.is_st` |
| 从历史最高值下跌 75% 时买入 | 历史最高 = 上市以来(数据自 2010-01-04 起)**后复权**收盘最高(含当日);买入条件 close ≤ high × (1 − 0.75) | `params.drawdown_buy: 0.75` |
| 价格恢复最高点一半时卖出 | 卖出条件 close ≥ high × 0.50;介于 25%~50% 之间的已持仓继续持有 | `params.recover_sell: 0.50` |
| 每两周调一次仓 | 调仓日 = 每隔一周的周首交易日(core.calendar 新频率 `biweekly_first`);信号在调仓日收盘生成 | `params.rebalance: biweekly_first` |
| 一共持仓 10 只,每次等额买入,不符合条件的卖出 | 先卖:已持仓中触发卖出条件、或退出 universe/变 ST 的清仓;再买:空位数 = 10 − 保留数,候选 = 满足买入条件且未持有,按"交易量"降序取前 N;**新仓各占当时总权益 10%,已持仓不动** | `params.n_positions: 10`,`risk.max_weight 0.10` |
| 选股条件为市场交易量最大排序 | 20 个交易日日均**成交额**(元)降序(成交量按股数会被低价股扭曲) | `params.volume_window: 20` |
| 初始资金 100,000 | 10 万元 | `--cash 100000` |
| 交易成本千分之五 | 买卖各 0.5% 全包(佣金口径,不再叠加印花税/过户费/最低佣金) | 策略包 `costs` |
| 滑点 2% | 买价 ×1.02、卖价 ×0.98(RQAlpha PriceRatioSlippage);因集合竞价撮合不加滑点,执行改为**次日收盘**成交 | 策略包 `execution: {mode: next_close, slippage: 0.02}` |
| 2019.1.1 至 2025.12.30 | 回测区间;基准 沪深300(000300.SH)+ 中证1000(000852.SH,深跌股偏小市值) | `--start/--end`,`benchmark` |

**证伪条件(先写死)**:全成本年化 ≤ 沪深300 年化;或最大回撤 > 60%;或参数平原不存在——回撤阈 {70%, 75%, 80%} ×
反弹阈 {40%, 50%, 60%} 的邻近结果出现悬崖(相邻格年化差 > 一半)。任一成立即证伪,结论如实进报告。

## 二、平台需补的机制(资产无关,进核心;数值在包)
1. `core.calendar.rebalance_dates` 新频率 `biweekly_first`(隔周的周首交易日);
2. `instruments.universe.BoardUniverse`(按板块 + PIT 上市/退市);策略包 universe 小节支持 `{boards: [...]}`;
3. `ctx.panel(name)`(≤asof 的后复权收盘 / 原始成交额面板,向量化算历史高点与均成交额)、`ctx.holdings()`(当前持仓权重,
   回测来自 RQAlpha 持仓,出信号来自上一份信号文件);
4. 执行模式 `next_close`(信号日收盘算、次日收盘成交,滑点生效)+ 策略包级 `execution` / `costs`;`plan_rebalance` 计入滑点;
5. RQAlpha 胶水从 `strategies/toy_lowvol_rq` 提为通用 `strategies/rq_runner`(旧名保留别名)。

## 五、风险与未知
- 全市场约 4900 只(含退市)预载,内存与时间较玩具策略大一个量级(预计单次回测 5~10 分钟,九宫格约 1 小时);
- "历史最高"受数据起点 2010 限制,2010 前上市股票的更早高点看不到(偏保守:高点可能被低估 → 买入条件更易触发);
- 2% 滑点 + 千五成本、两周换仓,成本极重,结果大概率显著低于无成本版——这是用户设定,如实呈现;
- 深跌股常伴停牌/退市:RQAlpha 会拒绝停牌交易、退市按末价折现,影响进报告。
