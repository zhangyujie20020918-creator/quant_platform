# 外部来源登记总表(规则自 cb_quant 平移,品种无关)

用法:PDF先放`inbox/`;登记完(标题/来源/核心信号三项都能填出来)后,按
`{年份}_{机构或作者}_{短标题}.pdf`重命名并移到`indexed/`,同时在下表加一行。三个核心
字段填不出的,不准登记,留在`inbox/`。可选笔记放`notes/`(文件名与indexed对应,.md后缀)。

**载体不限于PDF论文**:凡催生过任务卡或策略假设的外部文章,无论载体(论文/研报/
网页博客/帖子),一律入库登记。网页来源"来源"栏写"网页博客"(附URL),文件名用
`{年份}_{站点或作者}_{短标题}.html`(能抓到快照存`indexed/`,抓不到在登记表备注
"快照待人类补充",不阻塞登记本身)。

字段枚举:
**可复现性** = `数据已有` / `需补:XXX`(写清楚缺什么) / `不可复现`;
**状态** = `待读` / `已读-可试` / `已读-不适用` / `已入检验`(已进factors注册表)
/ `已读-本数据无法审理`(假设可能成立但当前数据条件测不出,写清楚卡在哪)。

| 文件名 | 标题 | 来源 | 核心信号(一句话) | 目标品种 | 可复现性 | 状态 | 关联因子id |
